# 기본 사용 규칙

- 기본 주황색: `#FF4B16` / 검정 배경: `#080808`. 디지털 파일은 sRGB 기준이다.
- 기본 로고: vectors의 세로 조합형. 흰색·검정색 버전은 배경과 대비가 확보되도록 사용한다.
- 작은 아이콘: icons의 5개 파형 심볼. 글자가 포함된 전체 로고를 파비콘으로 축소하지 않는다.
- 배경이 포함된 앱 아이콘은 OS가 마스킹하도록 사각형 원본을 사용한다. maskable 파일은 별도 여백을 확보했다.
- 비율을 바꾸거나 파형 일부를 잘라 사용하지 않는다. 기본형과 소형 적용형을 혼합해 임의 변형하지 않는다.
- 로고 외곽에 최소한 인접 파형 중심 간격 1개만큼의 빈 공간을 확보한다.
- 본문 서체·인쇄 CMYK·매장 안내 문구는 이번 자산에 포함해 확정하지 않았다.
- 흰색 로고는 흰 배경에서 보이지 않으므로 대비되는 배경에 배치한다.
