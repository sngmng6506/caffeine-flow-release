# Caffeine Flow · 기본 로고 원본 v1

확정 기준: 7번째 파형의 아래 턱을 수정한 발광 없는 주황색 시안.

- vectors/: 세로 조합형·심볼형 SVG, 주황·흰색·검정 각 1개.
- previews/: 투명 PNG와 검정 배경 확인용 이미지, 원본 비교 이미지.
- SVG는 이미지 삽입 없이 실제 경로로 구성했다. 파형과 글자 윤곽을 각각 편집할 수 있다.
- 글자는 원본 시안의 윤곽을 경로로 옮겼다. 폰트 설치가 필요하지 않으며 텍스트로 다시 입력하는 형식은 아니다.
- 기본 색상: #FF4B16. 화면용 sRGB 기준이며 인쇄 CMYK는 인쇄소 교정 후 확정한다.
- 래스터 경계를 단순화해 옮긴 원본이므로 확대 시 미세한 윤곽 정돈 여지가 있다. 상표 유사성·권리 검토 완료를 뜻하지 않는다.

## 디지털 적용물

- [icons/](icons/): 파비콘·Windows 앱·모바일 홈 화면 아이콘과 manifest 연결 예시.
- [social/](social/): 1200×630 링크 공유 이미지와 SVG 원본.
- [아이콘 미리보기](previews/icon-assets.png): 소형 아이콘의 실제 픽셀 크기와 적용형 비교.
- [기본 사용 규칙](USAGE.md).

파일 제작·보관 단계다. 운영 서비스와 설치 앱에 적용하려면 소스 저장소에서 정적 파일·메타 태그·빌드 설정을 연결해야 한다.
매장 QR 안내판은 사용자 컨펌 후 제작한다. 문구·매장 URL·인쇄 규격은 아직 확정하지 않았다.
현재 파형 전체를 16px로 축소하는 방식은 사용하지 않는다.
