`index.html`을 같은 폴더의 SVG와 함께 열면 시안을 전환할 수 있다. SVG 글자는 Noto Sans KR 기반 윤곽선으로 저장했다.

105×148mm 비율의 검토용 원본. QR은 스캔되지 않는 자리 표시다. 실제 매장 URL·QR과 인쇄 재단 여백·색상 교정은 별도 반영한다.
